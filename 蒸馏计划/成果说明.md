# 成果说明：纯 agnes 蒸馏 → 易记小段切分模型

> 本目录完成了一条"纯蒸馏"管线：不使用任何本地词典、派生数据、人工切分或考试题，
> 完全由大模型（agnes-2.0-flash）生成 24,149 个词的词素切分标签，再训练出一个
> 字符级小模型。输出风格是"直观、易记的常见字母块（伪词根），长词根切成可记忆小块"。

---

## 1. 成果总览

| 环节 | 结果 |
|---|---|
| 输入词表 | COCA 第 10000~40000 号词，去 `-` 合成词、去重、全长度 → **24,149 词** |
| 标签来源 | agnes-2.0-flash，`enable_thinking=false`，temp=0，批量 20 词/次 |
| 有效标签 | **23,207 / 24,149 = 96.1%**（942 条丢弃：675 段拼不回原词 + 267 解析失败） |
| 平均段数 | 2.60；多段词 20,269（87.4%） |
| 4+ 字母串一致性 | 73.1% → **82.3%**（一致性修复 pass 生效） |
| 训练/验证/测试 | 20,886 / 1,160 / 1,161（90/5/5，固定种子） |
| 模型 | 字符级局部窗口 MLP（窗口 6 字符、隐层 128），numpy 实现，无需 torch |
| 测试集 fidelity | gap 级 **P 0.796 / R 0.855 / F1 0.825**；词级完全一致 60.4% |
| 生成耗时 | ~94 分钟（2 份并行 + 断点续跑，无人值守） |

### 风格示例
```
absolute          -> ab . solu . te
inauguration      -> in . au . gur . at . ion
disinterested     -> dis . in . ter . est . ed
counterrevolutionary -> coun . ter . re . vol . u . tion . ary
titillation       -> ti . tillat . ion
```
部分词保持整词不分（`slot`、`franchiser`、`maoist`），这是"什么时候不该拆"的负样本。

## 2. 踩坑经验（值得反复看）

### 2.1 关闭 agnes 的 thinking（最关键的一条）
- 端点全部是推理模型：`agnes-2.5-flash` **过度推理，烧光 max_tokens 预算后正文为 0，完全不可用**。
- 标准"关推理"参数全部无效：
  - `reasoning_effort=none` → **HTTP 422**（直接拒绝）
  - `thinking:{type:disabled}`、`enable_thinking:false`、`reasoning:{enabled:false}` → 被忽略，`reasoning_tokens` 照旧。
- **正解**：请求体带 `"chat_template_kwargs": {"enable_thinking": false}`
  - 实测：`reasoning_tokens` 归 0，延迟 17.3s → **2.5s**，格式守规率 100%。
  - 写在 `agnes_client.py` 的 `chat()` 里。
- 注意：`agnes-2.0-flash` 其实也是推理模型（开 thinking 时 ~650 推理 token），但能正常完成任务，是可用选择。

### 2.2 prompt 设计
- 必须**严格规定输出格式 + few-shot 示例**（`word -> a.b.c`），否则模型自由发挥成解释文字。
- 规则句放在"请切分以下单词："之后，用自然语言描述切分哲学（这里是：伪词根、长词根切碎、100% 一致性）。
- 批量调用（10~20 词/批）让同批词一起出现，反而有利于"相同模式保持一致"。
- `temperature=0`；`max_tokens` 要留足（本管线 3000），即使关掉 thinking 也要防输出截断。

### 2.3 网络与代理
- agnes-ai.com 的 **DNS 被污染**：本地/阿里解析出 Meta（Facebook）IP 段，直连 443 超时。
- 必须走本地代理 `127.0.0.1:1080`（clash/v2ray 常见端口）。`agnes_client.py` 里用
  `urllib.request.ProxyHandler` 挂载。
- 公共 DNS（8.8.8.8）解析出的 IP 也不可达，直接信任代理即可。

### 2.4 标签后处理
- **拼接校验**：每段必须按顺序拼回原词（surface-tiling）。675 条因模型给出"词根本体形"
  （如 `scheming -> scheme.ing`，scheme 比表面 schem 多一个 e）被丢弃。真实词根版会更多。
- **一致性修复 pass**：统计重复 ≥2 次的 4+ 字母串，取多数边界模式，把偏离的词重切，
  前提是多数派足够强（≥3 次出现且强于 2 倍），防止误伤巧合共享子串（asterisk/austere 的 "ster"）。
- 经验：**"100% 一致性"是理想目标**；巧合共享子串决定了天花板（本批 82% 已是不错结果）。

### 2.5 模型训练取舍
- window6/hidden128 的 val_bce 0.1854 **优于** window8/hidden256 的 0.1892（大模型过拟合更快，早停）。小窗就够。
- 阈值扫描：最优阈值 0.38（在 val 上找），比默认 0.5 把 F1 从 0.816 提到 **0.825**。`eval_model.py` 里写死。
- numpy 纯实现即可（无 torch、py3.14 也能跑），训练 30 epoch 仅 ~9 秒。
- 坑：BCE 里 `(p - Y)` 与 `p` 形状（n,1）vs（n,）广播会爆内存（151k² 数组），必须先 `.reshape(-1)` / `[:,None]`。

### 2.6 可靠跑批
- 每批结果**逐条写 jsonl 并 flush**，`word` 为主键去重，**断点续跑**（已有则跳过）。
- 两份并行（按词表切半），各写独立文件再合并，时间减半。
- 请求重试 + 指数退避（`MAX_RETRIES=3, RETRY_BACKOFF=4`）。
- 无人值守 ~94 分钟跑完 24,149 词，无中断。

## 3. 用户怎么用

### 3.1 切词
```powershell
cd 蒸馏计划
python segment.py 单词1 单词2 ...
```
输出"易记小段"风格切分，例如：
```
python segment.py absolute inauguration antihistamine
absolute      -> ab . solu . te
inauguration  -> in . au . gur . at . ion
antihistamine -> an . ti . h . istamin . e
```

### 3.2 产物解读（`蒸馏计划\output\`）
| 文件 | 内容 |
|---|---|
| `words_all.txt` | 输入词表（24,149 词） |
| `llm_splits_raw.jsonl` | agnes 原始输出（含 meta：reasoning/completion tokens、耗时） |
| `llm_splits_clean.jsonl` | 通过校验 + 一致性修复后的**有效标签**（训练数据） |
| `llm_splits_invalid.jsonl` | 被丢弃的标签（bad_segments / unparsed） |
| `train.jsonl` / `val.jsonl` / `test.jsonl` | 90/5/5 拆分 |
| `model.npz` | 训练好的模型权重（W1/b1/W2/b2） |
| `report.txt` / `eval_report.txt` | 后处理指标 / 测试集 fidelity |
| `RESULT.txt` | 本成果的一次性存档 |

### 3.3 脚本职责速查
| 脚本 | 职责 |
|---|---|
| `config.py` | 路径、API、模型、批大小、种子等一切配置 |
| `select_words.py` | 从 COCA 切片选词、去重、长度分层抽样 |
| `prompt.py` | 切分 prompt 模板 |
| `agnes_client.py` | 代理 + 鉴权 + 关 thinking + 重试退避的 API 客户端 |
| `generate.py` | 批量生成、断点续跑、写 jsonl（`--words/--out/--batch`） |
| `postprocess.py` | 解析校验、拼接校验、一致性修复、指标报告 |
| `split_data.py` | 固定种子 90/5/5 拆分 |
| `train_model.py` | numpy 小模型训练（窗口 MLP + Adam + 早停） |
| `eval_model.py` | 测试集 fidelity 评估（gap F1、词级一致、样例） |
| `segment.py` | 训练后分词入口 |

### 3.4 如何复跑 / 扩展
- 全量生成：`python generate.py --words output/words_all.txt --out output/llm_splits_raw.jsonl --batch 20`
  （可分半并行：`--words output/half1.txt` + `half2.txt`）
- 换词表：`python select_words.py` 改 `config.py` 的 `RANGE_LO/RANGE_HI`，或直接喂自定义词表文件。
- 换风格：改 `prompt.py` 的规则句，重新生成即可（无需改任何其他代码）。
- 调模型：改 `train_model.py` 的 `WINDOW/HIDDEN/EPOCHS`；阈值在 `eval_model.py` 的 `THRESHOLD`。
