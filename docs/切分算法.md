# 交替方向贪心匹配算法

## 概述

两阶段流水线：Stage 1（派生追溯）→ Stage 2（交替方向词根贪心匹配）。

---

## 音节计数

**规则**：连续元音（`aeiouy`）算一组，一组 = 1 音节。

| 文本 | 元音组 | 音节数 |
|---|---|---|
| ta | a | 1 |
| tha | a | 1 |
| thea | ea | 1 |
| tac | a | 1 |
| tace | a-e | 2 |
| sedulous | e-u-o-u | 4 |
| capr | a | 1 |

y在词语的最左边算辅音。中间和最右边算元音
实现：`_count_syllables(text)` 扫描字符，遇元音且前一个不是元音则计数 +1。

---

## 主入口 `segment(word)`

1. 若整词 ≤1 音节 → 直接返回原词（不处理）
2. Stage 1：查 `word_derivations.json` 追溯派生链，如 `hedonist → hedonic.ism.ist`
3. 将 Stage 1 切分后的每段送入 Stage 2
4. Stage 1 无结果时，整词送入 Stage 2

---

## 两阶段交替 `_segment_word(word)`

```
第一轮：RTL 扫描整词（_match_one_pass）
  → 合并相邻未知段
  → 若 RTL 未命中任何根 → 整词返回未知

第二轮起：交替方向
  → 对每段未知段，若 ≤1 音节且本身不在 root_index 中 → 跳过
  → 否则运行 _match_one_pass(段文本，当前方向)
  → 合并相邻未知段
  → 若有新匹配 → 变换方向，继续
  → 若无新匹配 → 停止
```

方向切换顺序：**RTL → LTR → RTL → LTR → ...** 直至无新匹配。

---

## 单方向匹配 `_match_one_pass(text, direction)`

### LTR（左→右）

```
i = 0
while i < L:
    查找所有从 i 开始的候选根
    若存在：
        评分 → 选最高分 → 标记为已匹配段
        i += 根长度
    若不存在：
        剩余 = text[i:]
        若剩余 ≤1 音节 → 整块标记未知，停止
        否则 → 标记单字符未知，i += 1
```

### RTL（右→左）

```
i = L - 1
while i >= 0:
    查找所有以 i 结尾的候选根
    若存在：
        评分 → 选最高分 → 标记为已匹配段
        i = 根起始位置 - 1
        若剩余 text[:i+1] ≤1 音节 → 整块标记未知，停止
    若不存在：
        剩余 = text[:i]
        若剩余 ≤1 音节 → 整块 text[:i+1] 标记未知，停止
        否则 → 标记单字符未知，i -= 1
```

---

## 评分公式

LTR：

```
score = len(root) + max_len_starting_at(pos + len(root))
        + (is_affix ? 0.5 : 0)
        + (next_is_affix ? 0.3 : 0)
```

RTL：

```
score = len(root) + max_len_ending_at(pos - len(root))
        + (is_affix ? 0.5 : 0)
        + (prev_is_affix ? 0.3 : 0)
```

评分策略：1 步前瞻（lookahead）+ 来源加分。后缀因 affix 加分更易被选中。

---

## 短根限制（≤2 字母）

- **LTR**：只允许在段首（pos=0）或紧邻左侧已匹配段
- **RTL**：只允许在段尾（pos=L-1）或紧邻右侧已匹配段

防止 `tt`、`is` 等短串的误匹配。

---

## 1 音节段跳过规则

在交替循环中，若未知段 ≤1 音节且本身不在 `root_index` 中，则跳过不处理。
已在 `root_index` 中的 1 音节段（如 `ab`、`ad`、`am`）仍会被匹配。

在 `_match_one_pass` 中，匹配后/跳过后的剩余文本若 ≤1 音节，则整块留为未知并结束当前方向扫描。这防止了类似 `censure → cens + ure` 场景中 `cens` 被逐字符分解。

## 处理示例

### `censure`

| 步骤 | 操作 | 结果 |
|---|---|---|
| RTL 整词 | 自右匹配 `ure`（len=3）| 剩余 `cens` |

    剩余 `cens`（1 音节）→ 在 `_match_one_pass` 中停止，整块留未知

| LTR 遍历 | `cens` ≤1 音节且不在 root_index → 跳过 | - |
| 最终 | | `[cens].ure{d}` |

### `aberration`

| 步骤 | 操作 | 结果 |
|---|---|---|
| RTL 整词 | 自右匹配 `ion` → `errat`，剩余 `ab` | `ab` + `errat` + `ion` |
| LTR | `ab`（1 音节，在 root_index）→ 匹配 | `ab{d}` |
| 最终 | | `ab{d}.errat{d}.ion{d}` |

### `hedonist`

| 步骤 | 操作 | 结果 |
|---|---|---|
| Stage 1 | `hedonic.ism.ist` | 拆为 `hedonic`, `ism`, `ist` |
| RTL on `hedonic` | 自右匹配 `ic` ← `on` ← `hed` | `hed` + `on` + `ic` |
| RTL on `ism` | 1 音节不在 root_index → 跳过 | `ism` 未知 |
| RTL on `ist` | 匹配 `ist`（在 affix） | `ist{a}` |
| 最终 | | `hed{d}.on{a}.ist{a}` |

### `capricious`

| 步骤 | 操作 | 结果 |
|---|---|---|
| RTL | 自右匹配 `ious` ← `ic` ← `capr` | 整词覆盖 |
| 无未知段 | 停止 | `capr{d}.ic{a}.ious{a}` |

### `sedulous`

| 步骤 | 操作 | 结果 |
|---|---|---|
| RTL | 自右匹配 `ous` ← `ul` ← `sed` | 整词覆盖 |
| 无未知段 | 停止 | `sed{d}.ul{a}.ous{a}` |

### gap扣分的宽容度
考虑到英语会在词根词缀之间插入一个字母，纯粹缓解一下发音
比如 ology 和 logy ，o只是一个发音的补充，不一定有。
有时候还会删去一个重复字母，有时候用 e 代替 ex 
所以如果填补了词根词缀后，中间的gap只有1, 不扣分，并且根据它是元音还是辅音，它左右两边是元音还是辅音，做恰当的结合。
